Удобный список всех чатов Claude Code и Codex прямо в терминале.

Чем лучше встроенного `/resume`:

- **Все чаты в одном списке** — из всех каталогов сразу, Claude Code и Codex вместе. У каждого видно название, каталог, время, основную модель, текущий размер контекста, стоимость и добавленные/удалённые строки — тяжёлые чаты сразу заметны, а у выбранного — ещё и первый промпт.
- **Удобная навигация** — стрелки или `j`/`k`, листание страницами, колесо и клики мышью, сортировка по любой колонке и быстрый фильтр по словам (`/`).
- **Видны и скрытые чаты** — показываются все логи чатов на диске, даже те, которые встроенный интерфейс не отображает, и архивные чаты Codex.
- **Открывается любой чат** — даже если его каталог удалили или переместили.

## Установка

Нужен Python 3 на Linux или macOS (на Windows — через WSL: стандартного модуля `curses` там нет). Внешних зависимостей нет.

Одной командой, без клонирования:

```bash
mkdir -p ~/.local/bin && curl -fsSL https://raw.githubusercontent.com/VitaliyCloudDev/claude-interface/main/cc-sessions.py -o ~/.local/bin/claude-interface && chmod +x ~/.local/bin/claude-interface
```

Или из клона:

```bash
git clone https://github.com/VitaliyCloudDev/claude-interface.git
cd claude-interface && ./install.sh
```

Скрипт создаёт симлинк `~/.local/bin/claude-interface` → `cc-sessions.py` (так `git pull` сразу обновляет команду) и подсказывает, если `~/.local/bin` нет в `PATH`. После переноса каталога запустите его ещё раз.

## Использование

```bash
claude-interface          # TUI
claude-interface --list   # просто напечатать список
```

Колонки: время последнего изменения, название, основная модель, размер контекста, стоимость, добавленные строки (или удалённые, если их больше) и каталог. В логах Codex нет стоимости и диффа, эти ячейки пустые. Если каталога больше нет, в строке стоит `✗`. Внизу экрана показаны id, полный путь и первый промпт выбранного чата.

| Клавиша | Действие |
|---|---|
| ↑↓ / `j` `k`, колесо мыши | перемещение |
| PgUp / PgDn, Home / End | по страницам, в начало / в конец |
| клик по строке | выбор |
| ←→, клик по шапке колонки | сортировка по колонке |
| `r`, повторный клик по той же шапке | обратный порядок |
| `/` | фильтр: слова через пробел ищутся в названии, первом промпте, пути и id; Enter или Esc — закончить ввод |
| Enter | открыть чат |
| `q` / Esc | выход |

По Enter выполняется `cd <каталог> && claude --resume <id>` (для Codex — `codex resume <id>`). Claude ищет чат по каталогу запуска, поэтому удалённый каталог создаётся заново, пустым.

## Откуда берутся данные

- Claude Code: `~/.claude/projects/<каталог>/<session-id>.jsonl`. Берутся только файлы верхнего уровня, логи сабагентов пропускаются. Название — то, что задано через `/rename`, иначе автоматическое, иначе первый промпт.
- Codex: `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl` и `~/.codex/archived_sessions/` (`codex resume` предложит разархивировать). Названия — из `~/.codex/session_index.jsonl`; тред, продолженный в новом файле, показывается одним чатом.
- Пустые чаты, в которых нет ни одного сообщения, не показываются.

По умолчанию Claude Code удаляет логи старше 30 дней. Чтобы история хранилась дольше, увеличьте `cleanupPeriodDays` в `~/.claude/settings.json`:

```json
{ "cleanupPeriodDays": 3650 }
```
